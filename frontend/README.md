# SmearDx

Cinematic Next.js frontend for the blood smear analyzer.

## Stack
- Next.js App Router
- GSAP + ScrollTrigger
- Lenis smooth scroll
- React Three Fiber particle field

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Scroll the hero to split **Born of Science** and reveal the smear / particle field. The laboratory section is a frontend preview until the YOLO API is connected.
